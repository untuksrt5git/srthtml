# SRT Batch Translator v2.8 Auto Gemini

## Aplikasi
GitHub Pages: https://untuksrt5git.github.io/srthtml/

## Ekstensi
Folder `extension` berisi ekstensi Chrome Manifest V3 untuk Vivaldi Android 8.2+.
1. Ekstrak folder ekstensi di HP.
2. Di Vivaldi, aktifkan Desktop Site bila diperlukan.
3. Buka Extensions → Manage Extensions → Developer Mode → Load unpacked.
4. Pilih folder `extension`.
5. Buka GitHub Pages aplikasi dan tab Gemini yang sudah login.

Catatan: otomasi bergantung pada struktur halaman Gemini yang dapat berubah. Uji dahulu dengan beberapa dialog. Jangan tutup tab Gemini saat proses berjalan.
