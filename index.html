SRT Batch & Sub-Batch JSON Translator Helper v3.0

Versi 3.0 — Setiap Batch Utama dapat memiliki ukuran Sub-Batch sendiri, dengan Auto Split saat diperlukan, validasi hasil, dan autosave. Gunakan tab Gemini yang sudah login di Vivaldi.

Autosave: menunggu data.

Hapus Autosave menghapus salinan otomatis browser tetapi membiarkan proyek yang sedang terbuka tetap tampil. Reset Proyek menghapus seluruh progres dan mengosongkan halaman.

Progres disimpan otomatis di browser HP ini. Ekspor JSON secara berkala untuk cadangan jika data browser terhapus atau Anda pindah perangkat.

Setelah file dipecah, setiap Batch Utama memiliki pengaturan Sub-Batch sendiri. Ukuran satu Batch bisa berbeda dari Batch lainnya.

2. Batch Utama dan Sub-Batch

Atur ukuran Sub-Batch pada masing-masing Batch Utama, lalu tekan Cabang / Sub-Batch. Setiap Batch boleh memakai ukuran yang berbeda.
